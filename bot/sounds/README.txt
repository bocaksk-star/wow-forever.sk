Put your voice clips here (.mp3 / .ogg / .wav / .m4a).
The FILE NAME decides when a clip plays automatically:
  pull*.mp3  -> on /pull          (e.g. pull_nespekuluj.mp3)
  wipe*.mp3  -> on /wipe          (e.g. wipe_a_je_to_v_riti.mp3)
  kill*.mp3  -> on /wipe killed:True
  join*.mp3  -> when the bot joins voice
If several match, a random one plays. Any clip can be played with /sound name:<file name>.
